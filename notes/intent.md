# Project Intent

This practice project is a scoring, ranking, and tracking program for a cards league.

## High-Level Requirements

- Score and rank players across multiple card game types.
- Store historical player and game performance.
- Utilize configurable seasons to analyze relative performance and rankings.
- Support individual and team performance where applicable.
- Calculate rankings using configurable scoring rules.
- Support historical comparisons across seasons.

## C++ Concepts

Throughout the project, deliberately incorporate and explore the following concepts.

### Use

- References and pointers.
- Classes and structs.
- Basic OOP: composition, inheritance, and polymorphism.
- Constructors, destructors, and access control.
- Function overloading.
- Namespaces.
- Const correctness.
- Standard Library containers and utilities.
- Enums and strongly typed enums.
- Iterators.
- Templates.
- Exceptions.
- CMake and compilation.

### Understand

- RAII.
- Smart pointers and ownership.
- Copy and move semantics.
- STL algorithms.
- Value semantics vs. reference semantics.
- Object lifetimes.

### Advanced Concepts (Use if Applicable)

- Operator overloading.
- Function objects and lambdas.
- Concepts and constraints (C++20).
- Multithreading and synchronization.
- Asynchronous execution.
- Static and dynamic libraries.
- Time and duration handling (`std::chrono`).
- Profiling and performance analysis.

## Learning Expectations

- **Use:** Implement the feature and understand its practical application.
- **Understand:** Be able to explain what it does, why it exists, and when to use it.
- **Advanced:** Explore when a practical requirement justifies its introduction.

## Development Philosophy

- Prefer practical implementation over isolated exercises.
- Introduce abstractions when they solve an actual problem.
- Avoid unnecessary complexity and premature optimization.
- Compare C++ approaches against equivalent C implementations where useful.
- Prioritize understanding over simply producing working code.
